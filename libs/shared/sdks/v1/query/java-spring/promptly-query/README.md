## Overview

A **read-only Java SDK** for querying the Promptly REST API from JVM-based applications. Built on **Spring WebClient** for non-blocking, reactive HTTP calls. This SDK is ideal for:

- AI agent services that need to **fetch prompts at runtime**
- Backend microservices consuming Promptly data
- Internal tools that query prompts, projects, or search results

## Quick Start

```java
import com.spectrayan.promptly.query.*;
import com.spectrayan.promptly.query.model.*;
import com.spectrayan.promptly.query.api.PromptlyQueryApi;

public class Example {
    public static void main(String[] args) {
        ApiClient client = Configuration.getDefaultApiClient();
        client.setBasePath("http://localhost:8080");

        PromptlyQueryApi api = new PromptlyQueryApi(client);

        // Fetch a prompt for your AI agent
        DeliveryResponse prompt = api.deliverPrompt(

            "agent-1"        // agent
        );
```
