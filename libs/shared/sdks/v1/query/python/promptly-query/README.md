## Quick Start

```python
import promptly_query
from promptly_query.rest import ApiException

# Configure the client
config = promptly_query.Configuration(
    host="http://localhost:8080"
)

# Fetch a prompt for your AI agent
with promptly_query.ApiClient(config) as client:
    api = promptly_query.PromptlyQueryApi(client)

    try:
        response = api.deliver_prompt(
            app_id="my-app",
            usecase="summarization",
            agent="agent-1"
        )
        print(f"Prompt content: {response.content}")
    except ApiException as e:
        print(f"API error: {e}")
```

### Usage with LangChain

```python
from langchain.prompts import PromptTemplate

config = promptly_query.Configuration(host="http://localhost:8080")

    response = api.deliver_prompt(app_id="my-app", usecase="qa")
```
