## Open Source Ecosystem

Promptly stands on the shoulders of remarkable open-source projects:

- **Spring Framework & Spring Boot** — Core reactive platform foundation.
- **Spring Modulith** — Architecture verification and event-driven modular monolith boundaries.
- **Spring AI** — Multi-provider LLM integrations (OpenAI, Gemini, Anthropic, Ollama).
- **Angular & Angular Material** — Modern frontend application framework and Material 3 UI.
- **Monaco Editor** — Professional-grade in-browser code and prompt editing.
- **MongoDB & PostgreSQL / pgvector** — High-performance document and relational vector persistence.
- **Resilience4j** — Resilient reactive rate limiting and fault tolerance.
